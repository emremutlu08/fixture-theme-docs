Fixture theme documentation

Shopify theme by Emre Mutlu, Digimaps Core. Support: Fixture theme support form

Fixture is a Shopify theme for sports and teamwear stores. It covers the usual storefront, and adds a jersey customizer for stores that sell personalized kit.

This document uses the same wording as the theme editor, so a heading here matches the label you see in Shopify admin.

Install the theme

  1. In Shopify admin, go to Online Store > Themes.
  2. Under Theme library, choose Add theme > Upload zip file and select the Fixture zip.
  3. Choose Customize to open the theme editor.
  4. Choose Publish when you are ready for the theme to go live.

Fixture works without custom metafields; the Product details section can read an optional product metafield custom.key_features. It needs no paid apps. Collection and search filters come from Shopify's free Search and Discovery app. Every setting lives in the theme editor. The theme reads only the product, collection, page, blog and navigation data you already have.

Theme settings

Open the theme editor and choose the settings icon at the bottom of the left panel. Settings are grouped as follows.

Layout

Setting What it does
Page width Maximum content width, in pixels
Grid horizontal gap Space between grid columns
Grid vertical gap Space between grid rows

Color mode

Enable light and dark mode lets visitors switch between light and dark appearance. Default appearance sets the starting mode, with the values Light, Dark and Use device setting. Dark background, Dark surface, Dark surface text, Dark text, Dark accent and Dark accent text set the colors used in dark mode.

Breadcrumbs

Show breadcrumbs on pages and collections turns the breadcrumb trail on for those pages. Product pages have their own setting, Show breadcrumb navigation, in the Product information section.

Colors

Fixture uses eight color settings: Text, Background, Secondary background, Secondary background text, Accent, Accent text, Highlight and Highlight text.

Every background has a matching foreground, so text stays readable when you change a background. Sections also offer a Color palette setting with the values Light, Soft, Dark, Accent and Brand colors. Choosing Brand colors makes a section use the background and text you set here.

Typography

Heading font and Body font each take a Shopify font. Heading size and Body size set the type without you editing each section. Additional body text scaling adjusts body text as a percentage, with 100% as the default. Bold, italic and bold italic weights load automatically for the fonts you pick.

Shapes

Global corner radius sets one radius for theme components. Turn on Apply global radius to use it. Button corner radius, Input corner radius, Card corner radius, Media corner radius and Badge corner radius control each component, plus Button border thickness. Set these once and every section follows. Product and section settings with their own radius keep precedence.

Product cards

Show the "New" badge, Show the "Popular" badge and Show the "Best seller" badge appear on products tagged new, popular and best-seller. Show sale badges controls sale badges on every product card. Sale badge format (Percentage, Amount or Sale label) and Sale badge indicator (Icon or Text) set how a sale badge reads. Sale badge background, Sale badge text and Sale badge border set its colors. Leave a color empty to use Highlight for the background and border, or the contrast color for the text.

Cart recommendations

Show cart recommendations turns this on. Source chooses where the products come from, with the values Selected products, Collection, Shopify complementary products and Selected + Shopify complementary. The rest control the Heading, the Desktop layout and Mobile layout (Stacked cards or Horizontal carousel), the Product photo size (Compact, Balanced or Large) and the Option spacing (Compact or Comfortable).

Home page motion

Motion style sets how much motion the home page uses: Off, Subtle or Expressive. The default is Subtle. Reveal sections on scroll reveals each section as a visitor scrolls to it. Use reveal motion on mobile turns that reveal on for phones as well.

Search

Show search suggestions shows suggestions as a customer types. Show price in suggestions adds a price to each suggestion.

Social media

Links for Instagram, Facebook, TikTok, YouTube and Pinterest. Leave a field empty to hide that icon.

Brand

Set the Favicon, and a Default meta description that the theme uses where a page has none.

Product recommendations

Hide jersey customizer products keeps those products out of recommendations, which is useful when they are not meant to be bought directly. Collection to exclude removes everything in a collection from recommendations.

Header and footer

The header and footer are section groups, so you edit them in the theme editor like any other section and they apply to every page.

The Header section covers the layout (Logo left, navigation beside, Logo centered, navigation below, or Centered logo, drawer navigation), sticky behavior, the menus, the search field, the country and currency selector, the language selector, and the account link. Use nested menus in Shopify admin under Online Store > Navigation to get multi-level dropdowns.

The Footer section covers menus, the newsletter, payment icons, social icons and the copyright line.

The Announcement bar sits above the header and takes multiple messages as blocks.

The Welcome popup lives in the footer group. Open trigger defaults to After delay. Choose After browsing interaction to wait for both the configured minimum delay and a completed click, tap, key release or mouse-wheel scroll outside links and controls. Form entry and purchases do not trigger it. Without browsing interaction, the popup stays closed. The Show only on the home page and Show again settings control where and how often a visitor sees it.

Home page

Add sections from Add section in the theme editor. The ones intended for the home page are:

Hero, Media collections, Collection tabs, Campaign showcase, Collection cards, Product rail, Featured products, Featured product, Bundle builder, Product kit, Hotspots, Lifestyle showcase, Video, Image comparison, Blog posts, Logo list, Icon benefits, Quote, FAQ, Email signup, Product comparison and Custom Liquid.

The Countdown timer section can be added to any page. It is not part of the demo home page.

Further storytelling and layout sections: Category grid, Product set, Statistics, Story grid, Principles, Feature strip, Page header, Before and after, Campaign pair, Empty state cards, Editorial page, Editorial article, Article listing, Contact details, Collection list and Product details.

Each of these also works on a page template, so you can build landing pages from the same parts.

Bundle builder

The Bundle builder section lets shoppers choose products and adds them to the bag in one step. The section applies no discount itself.

To offer a bundle price, create an automatic discount in Shopify admin:

  1. Go to Discounts and create an automatic discount for the eligible products.
  2. Set the minimum quantity to the number in Products to choose.

Shopify applies the discount in the bag and at checkout. Optionally, type a short description in Offer note.

Product pages

The Product information section is block driven. Add, remove and reorder these blocks:

  • Vendor, Product heading, SKU, Price, Variant picker, Quantity selector, Buy buttons, Description
  • Product features, Complete the kit, Text note, Collapsible information
  • Custom Liquid, and any app block

The heading blocks (Vendor, Product heading, SKU) render as one group, and the purchase blocks (Variant picker, Quantity selector, Buy buttons) render as one group. Each group appears at the position of its first block, and the order inside a group is fixed. The older Product options and purchase block still works. When it is present, the new purchase blocks are ignored. The legacy Show vendor and Show SKU settings of the Product heading block still work, and each line renders once even when a Vendor or SKU block is also added.

Key settings: gallery position, desktop and mobile gallery layout, whether to show breadcrumb navigation, the compact sticky cart bar, and a size guide page. The size guide page, gift card recipient form, local pickup availability and accelerated checkout settings are on the Buy buttons block.

Complete the kit has a Source setting. Shopify complementary products uses Shopify's own recommendations, Collection draws from a collection you pick, Selected products uses a list you choose, and Selected + Shopify complementary combines the two.

Variant images change the gallery when a customer selects a variant, so upload an image per color.

Collection and search

Collection page handles the product grid, sorting, pagination and filtering. Filters come from Shopify's Search and Discovery app settings, so add filters there and the theme shows them. Customers can filter by availability, price, product type, vendor and variant options.

Collection index lists every collection. Search results handles search, including products, pages and articles.

Cart

Cart works as a page or as a side drawer, set by Cart type in theme settings. It shows per item and per order discounts, selling plans, unit prices, order notes and accelerated checkout buttons.

Jersey customizer

This is Fixture's own feature, for stores selling personalized kit.

  1. Add the Jersey customizer section to a page or product template.
  2. Add a Jersey model block for each jersey style and choose its product.
  3. Set a front image and, if you have one, a back image on each block.
  4. Add Player blocks if you want a roster a customer can pick from.
  5. Set the print colors you offer with Print color blocks.

Printing pricing decides how personalization is charged. Paid printing, uses product variants uses a product option on the jersey product itself, which is the recommended setup, so create the option named in Product option name with the values you want to charge for. Printing included at no extra charge adds personalization at no cost.

The name and number font settings control the print preview. Set the print area with the placement settings on each model block.

Customer accounts

Fixture supports both of Shopify's account systems. With classic accounts the theme renders the login, register, account, addresses, order and password reset pages. With new customer accounts Shopify hosts those pages and the theme shows the account link in the header.

Frequently asked questions

Do I need any apps? No paid apps or custom metafields are needed. Collection and search filters come from Shopify's free Search and Discovery app.

Why are my collection filters missing? Filters come from Shopify's Search and Discovery app. Add filters there and they appear on collection and search pages.

Why does the jersey customizer show no models? Each Jersey model block needs a product selected. A block with no product is skipped on the storefront, and the theme shows a note in the editor instead.

Can I change the fonts to my own brand font? Fixture uses Shopify's font picker, which covers the fonts Shopify hosts. Custom font files are not supported.

Why does my section look different on mobile? Most sections have separate mobile settings, usually under Mobile. Check there before changing the desktop values.

How do I hide the welcome popup? Open the Welcome popup section in the footer group and turn off Show popup.

Why is my variant image not changing? The gallery changes when the selected variant has its own image. Upload an image per color on the product, then assign it to those variants.

Can I use the theme on more than one store? Each store needs its own theme purchase from the Shopify Theme Store.

How do I reset a section to its defaults? Remove the section and add it again from Add section.

Editing theme code

Duplicate the theme before you edit any code. Go to Online Store > Themes, choose Actions > Duplicate on Fixture, and make your changes on the copy. A mistake in live code can break the storefront for every visitor.

Code edits are not covered by theme support, and custom coding tutorials are not provided. For custom work, hire a Shopify Partner from the Shopify Partners directory.

Theme updates do not merge code edits. Keep a record of the changes you make so you can reapply them to a newer version of the theme.

Contact form limits

The Contact form section uses Shopify's own contact form, so it inherits two platform limits that no theme setting can change.

  • No file uploads. Shopify's contact form accepts text fields only. To let customers attach a file, use a form app from the Shopify App Store and place it on the page with the Custom Liquid section.
  • No automatic reply. Shopify sends the message to the store email address but does not answer the customer. Set up an auto responder in your email provider, or use a helpdesk app, if customers should get an immediate acknowledgement.

Everything else on the form, the field set, the required fields, the success message and the error messages, is handled by the theme.

Support policy

To request help, use the support form at https://emremutlu08.github.io/fixture-theme-docs/support.html. It asks for your name, email, store URL, a subject and a description of the problem, and you can attach screenshots or files. A confirmation email arrives as soon as you send the form.

Include the page address, the steps to reproduce the issue, your theme version, device and browser.

Replies arrive within two business days.

Theme defects such as a broken layout, a dead link or a logic error are fixed in a timely manner. Critical bugs are fixed immediately.

Support covers theme settings questions and reproducible theme issues. It does not cover store configuration, third-party apps, customizations or custom development, which can be arranged separately.
